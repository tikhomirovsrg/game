# Lumen City · Город, который загорается

Офлайн-головоломка для Android: поворачивай участки электросети, зажигай дома и восстанавливай тихую гавань. Первый игровой прототип для проверки интереса и удержания; показатели аудитории пока не измерены.

## В этой версии

- 40 последовательно открывающихся уровней, поля от 3×3 до 6×6.
- Все схемы детерминированы и имеют проверенное решение. Генератор и закреплённые участки не вращаются.
- Победа требует подключить **все участки**, не оставляя открытых концов.
- 5 объектов города и 5 коротких историй: пекарня, сад, трамвай, обсерватория, маяк.
- Одна искра за первое прохождение; все 40 искр покрывают восстановление города. Повторы и ежедневные задачи валюты не дают.
- Звёзды за экономное решение; бесплатные подсказки, отмена хода, перезапуск. Отмена не возвращает уже потраченные повороты.
- Ежедневная задача по локальной дате устройства, личный рекорд и отправка результата через системное меню.
- Автосохранение после действия, восстановление незаконченного уровня, русский/английский интерфейсы, звук и вибрация.
- Никаких сетевых разрешений, рекламы, покупок, обязательных аккаунтов или потери жизней.

Онлайн-рейтинга и серверной аналитики нет. Честное соревнование в этой версии — сравнение одной и той же ежедневной схемы с друзьями. Город построен на оригинальной SVG-графике; внешних изображений, шрифтов и CDN в игре нет.

## Установить на Android

Открой **Actions → Android APK and game checks → успешный запуск → Artifacts → lumen-city-debug-apk**. Распакуй ZIP и установи `app-debug.apk`, разрешив установку из выбранного источника. Нужны Android 8.0+ и актуальный Android System WebView.

Это **debug APK для тестирования**, не пакет для публикации в Google Play. Разные машины CI создают разные тестовые ключи: при конфликте подписи понадобится удалить старую тестовую установку (её локальные сохранения будут потеряны). Для релиза нужен постоянный приватный ключ, актуальная проверка требований Google Play и тестирование на устройствах.

## Сборка

Требования: JDK 17, Android SDK Platform 35, Build Tools 35.0.0. Wrapper использует Gradle 8.11.1; Android Gradle Plugin 8.9.2.

```sh
export ANDROID_HOME=/path/to/android-sdk
./gradlew lintDebug assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Windows: `gradlew.bat assembleDebug`. Проект также открывается в Android Studio.

## Быстрая проверка игровой части

```sh
npm ci
npm test
npm run preview
# http://127.0.0.1:4173
npx playwright install chromium
npm run test:ui
```

`npm test` проверяет все 40 уровней, 365 ежедневных схем, правила соединения, валюту, повторные награды и восстановление сохранений. UI-проверка проходит обучение, строит пекарню, проверяет возврат в игру, локализацию, ежедневную задачу и размеры экранов. Скриншоты сохраняются в `test-results/`.

## Устройство проекта

| Путь | Назначение |
|---|---|
| `app/src/main/assets/engine.js` | Чистые правила, генератор, прогресс и экономика |
| `app/src/main/assets/app.js` | Интерфейс, локализация, управление, сохранение |
| `app/src/main/assets/city.js` | Оригинальная векторная сцена города |
| `app/src/main/assets/style.css` | Адаптивная тема |
| `app/src/main/java/.../MainActivity.java` | Android WebView, локальные ресурсы, Back и Share |
| `docs/PLAYTEST.md` | План тестирования и расходования бюджета до $1 000 |

Android-оболочка использует `WebViewAssetLoader` с HTTPS-origin для ресурсов внутри APK. Доступ к файлам, внешние переходы и сетевые запросы отключены. Ключи подписи, SDK, локальные сборки и зависимости не коммитятся.

## Данные и ограничения

Сохраняются только локальный прогресс и последние 300 игровых событий. Экспорт отчёта в настройках открывает системное меню; передача происходит только по действию игрока. Централизованные D1/D7/D30 этот прототип **не измеряет**. Переустановка, очистка данных приложения и сброс прогресса удаляют сохранения. Одновременно хранится один незаконченный уровень.

Решаемость уровней проверена автоматически; интересность, сложность и месячное удержание требуют реальных игроков. Количество уровней само по себе не гарантирует месяц игры. До платного привлечения нужны реальные устройства, анализ первых сессий и согласованный сбор метрик.
